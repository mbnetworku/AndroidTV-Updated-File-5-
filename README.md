# Android TV apps (Android 5.0+, 32-bit ARM)
Install with: adb install -r <file>.apk

- AppleTVHome-1.0.6.apk: Apple TV style launcher (https://github.com/mbnetworku/Apple-TV-launcher)
- VolumeBar-1.1.apk: volume control in the notification area
- UTVPlus-32.68-armeabi-v7a.apk: YouTube TV client (UTV Plus) (SmartTube based)

Google Play services is not included on purpose (Google's software, get it from APKMirror).
